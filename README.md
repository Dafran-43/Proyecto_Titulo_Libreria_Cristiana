# Proyecto de Título – Librería Cristiana

## 1. Descripción del proyecto

Este proyecto consiste en el desarrollo de una plataforma web orientada a la búsqueda, recomendación y reserva de literatura cristiana.

Mi propósito es crear una herramienta que permita a las personas encontrar libros cristianos de acuerdo con sus intereses y necesidades de lectura, facilitando el acceso a materiales de formación y crecimiento espiritual.

La plataforma está pensada como parte de un futuro emprendimiento de librería cristiana en Copiapó, Chile.

## 2. Objetivo del proyecto

Desarrollar una plataforma web que permita consultar un catálogo de libros cristianos, realizar búsquedas por título o temática, recibir recomendaciones de lectura y solicitar reservas de libros para su posterior retiro presencial.

## 3. Tecnologías utilizadas

Para desarrollar el prototipo estoy utilizando las siguientes tecnologías:

- **Frontend:** Vue.js, HTML, CSS y JavaScript.
- **Backend:** Node.js y Express.
- **Base de datos:** PostgreSQL.
- **Editor de código:** Visual Studio Code.
- **Control de versiones:** Git y GitHub.

## 4. Funcionalidades del prototipo

### Catálogo de libros

Permite visualizar los libros disponibles en la base de datos, incluyendo información como título, descripción, temática y precio.

### Búsqueda de libros

Permite buscar libros por título o temática.

### Filtro por temática

Permite seleccionar una categoría para facilitar la búsqueda de literatura cristiana.

### Recomendaciones de lectura

Incluye opciones de recomendación según intereses de lectura, como aprender a orar, fortalecer la fe, crecer espiritualmente y conocer sobre las misiones.

### Formulario de reserva

Permite seleccionar un libro e ingresar un nombre y un medio de contacto.

Actualmente, esta funcionalidad es demostrativa. Los datos ingresados se validan en la interfaz, pero todavía no se almacenan como reservas reales en PostgreSQL ni modifican el inventario.

## 5. Estructura del proyecto

- `backend/`: contiene el servidor Express y la conexión con PostgreSQL.
- `frontend/`: contiene la interfaz web desarrollada con Vue.js.
- `.gitignore`: evita incluir archivos privados, dependencias y otros elementos innecesarios en el repositorio.

## 6. Estado actual

El proyecto se encuentra en etapa de desarrollo y pruebas.

Hasta el momento he desarrollado un prototipo que permite consultar libros desde PostgreSQL mediante una API, visualizar el catálogo, realizar búsquedas y filtros, presentar recomendaciones temáticas y demostrar el funcionamiento de un formulario de reserva.

Todavía debo continuar desarrollando y comprobando las funcionalidades necesarias para completar la plataforma.

## 7. Próximas actividades
